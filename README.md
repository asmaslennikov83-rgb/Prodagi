# WB Orders Telegram Bot

Telegram-бот формирует Excel по заказам Wildberries из одного или двух кабинетов.

## Что умеет
- кабинет 1 / кабинет 2 / объединение двух кабинетов;
- быстрые периоды 7, 14, 30, 60, 90 дней — сегодняшний день не включается;
- произвольный диапазон дат до 90 дней;
- весь ассортимент попадает в Excel, включая товары с 0 заказов;
- колонки: баркоды, артикул продавца, nmID, наименование, размер, FBO, FBS, всего;
- если размера нет, выводится `0`;
- отменённые заказы исключаются;
- при объединении кабинетов товар сопоставляется по пересечению любого из его баркодов; резервно — по артикулу продавца + размеру.

## API-токены WB
Для полноценной работы токены должны иметь права минимум на категории **Контент**, **Статистика/Отчёты** и **Аналитика** (для резервного Order Feed).

## Установка
1. Скопируйте `.env.example` в `.env`.
2. Вставьте Telegram token и два WB API token.
3. Запустите:

```bash
docker compose up -d --build
```

Логи:
```bash
docker compose logs -f
```

Без Docker:
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## Важное про источники заказов
Бот сначала использует подробный `GET /api/v1/supplier/orders`, потому что он содержит `barcode`, `warehouseType`, `date` и `isCancel`, необходимые для точного FBO/FBS отчёта по дате заказа.

Если WB уже отключил этот метод, бот автоматически пробует новый `POST /api/analytics/v1/order-feed`. Новый метод имеет ограничение максимум 31 день и выбирает записи по дате текущего статуса, поэтому для отчётов 60/90 дней без старого Orders API бот покажет понятную ошибку.
